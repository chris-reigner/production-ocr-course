GPU enablement on EKS

Two layers before a pod can see a GPU

The driver makes the hardware work; the device plugin makes Kubernetes aware it exists. You need both.
Ships in the AWS GPU AMI
Layer 1 · node-level
Host GPU enablement
NVIDIA kernel driver
The .ko module — must match the running kernel.
NVIDIA container toolkit
Lets containerd expose /dev/nvidia* into pods.
The one piece you install on AWS
Layer 2 · cluster-level
Kubernetes GPU enablement
NVIDIA device plugin (DaemonSet)
Advertises nvidia.com/gpu: N to the kubelet. Without it, the scheduler can't "see" the GPU at all.
kube-scheduler can now place a pod that requests resources.limits: nvidia.com/gpu: 1.
